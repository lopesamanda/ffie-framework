# FFIE Framework

Site e ferramenta do **Feminist Foresight in Innovation Ecosystems** — tese de doutorado em Design.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Framer Motion (transições na matriz)
- Supabase (submissões + storage) — em breve

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Documentação

- `docs/FFIE_product_brief.md` — escopo e arquitetura de informação
- `docs/ffie_atlas_seed.md` — dados seed do Atlas (8 protótipos diegéticos)
